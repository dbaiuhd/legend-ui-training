# 传奇手游界面适配规则

## 使用范围

用户制作的是手游界面时读取本文件，再按功能读取图鉴、圆盘、礼包或活动参考。经典传奇端游截图只提供材质、图形语言和信息层级，不要求照搬窗口尺寸、鼠标悬停态、桌面 HUD 或拥挤的 PC 排布。

## 触控与布局

- 先确认横屏或竖屏、目标分辨率、常用安全区和实际显示比例。没有明确画幅时，保持原型比例并预留状态栏、刘海、圆角和手势区域的安全边距，不虚构已经适配某个机型。
- 主要按钮和可点击槽位按触控目标设计，建议以约 44–48 dp 作为常用下限，再按游戏实际比例调整。按钮文字、图标和点击反馈留出足够内边距，避免相邻操作误触。
- 同一操作区内保持稳定的按钮高度、左右边距、槽位尺寸和间距。列表行高由中文可读性与触控高度共同决定，不把桌面端小字和窄行直接缩放到手机上。
- 横屏界面可使用左侧导航、中央主体、右侧属性的三段关系，但移动版要减少导航宽度、扩大操作区，并将高频确认、领取、购买或进入操作放在拇指容易到达的下方或侧下方。竖屏界面优先采用顶部页签、内容滚动区和底部固定操作栏。
- 弹窗内容超过一屏时拆成清楚的分区或滚动区域，标题、关闭、返回和底部主要操作保持稳定，不让操作按钮随长列表消失。
- 适配不同宽高比时优先保持主体、奖励列、属性行和操作按钮的相对关系。可裁切背景和外部装饰，不能裁切标题、卡片、关键数值和主要按钮。

## 视觉语言

- 继续使用传奇端游可识别的黑铁、暗石、旧银、古铜、雕刻、磨损和局部主题光，把材质做成适合小屏阅读的分层表面。内容床、正文、属性表和奖励区需要比外框更安静。
- 手游可以有更大的触控按钮、更明确的选中态、按下反馈和局部光效，但不把所有控件做成发光胶囊、玻璃卡片或无差别渐变。按钮轮廓应服务于点击状态和文案识别。
- 端游参考中的鼠标悬停、密集侧栏、极小字体、顶部桌面 HUD 和连续窄边框只作为来源线索。移动版要改成触控可识别的选中、按下、禁用、冷却和可领取状态。
- 低分辨率参考中的锯齿、糊字、压缩块和拥挤间距不作为输出标准。缩小到真实手机显示尺寸检查中文、数字、图标和按钮仍能辨认。

## 手游验收

检查安全区、触控目标、误触风险、横竖屏裁切、滚动后的标题和底部操作、文字可读性、选中/按下/禁用状态、以及主题光对功能信息的遮挡。提示词中写明目标方向、参考图用途、固定画幅或响应式要求；未知内容留给当前原型，不从截图补写玩法。
