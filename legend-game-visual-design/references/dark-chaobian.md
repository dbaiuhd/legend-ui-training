# 暗黑超变

适用范围：用户单独命名的超变传奇游戏界面系列。当前以 2026-11-18 修订为准：黑金主调，仅少量红色魔纹装饰。它是独立风格分支，不覆盖其他传奇项目。功能布局按本次原型和实际内容选择。

## 当前确认要求

- 整体风格定为黑金：黑色与近黑底面，金色用于标题、细描边和关键操作，正文保持清晰的冷灰色。
- 不使用黑铁材质，不沿用粗粝铸铁、铁锈、铆钉、机械连接件等表现。
- 装饰只保留一点点红色魔纹，局部、低占比、克制发光。取消旧规范中的骷髅、血痕、炼狱火焰和尖刺装饰。
- 用户将本套规范单独命名为“暗黑超变”，并纠正了厚重边框：默认薄边、窄结构、减少套框，留足功能区。
- 原始需求截图仅作历史来源，其中黑铁、暗红标题、骷髅、血痕、火焰等已被本次修订覆盖，不能重新引入。
- 沙城传送原型仅用于布局与功能内容，不是蓝色霓虹风格依据。已生成的两版均未经用户认可；第二版仅作为本次边框过重反馈对应的反例，不作为正例学习。

## 材质与信息层级

黑色与近黑承担主体面积，通过细腻、低对比的哑光纹理和小幅明暗差区分底板与功能区。金色承担标题、细线、选中态和按钮重点，可在暗金与适度亮金之间建立层级，保持文字清楚，避免大面积镜面反光。

标题使用金色，正文使用冷灰，关键数值按功能适量用金色强调。红色仅用于少量魔纹点缀，不再作为大标题、整片页签或大面积按钮底色。奖励图标可保留自身颜色；已有玩法状态色按实际功能处理，不扩张为背景装饰。

底面纹理保持安静，不要求破碎石板、大裂缝或重度磨损。表面质感可通过轻微细纹、柔和凹槽和接触阴影体现，避免用粗铁结构或强倒角制造厚度。

## 边框纠偏

本节是针对用户反馈制定的默认执行标准，细度数值是设计起点，不是用户给定的固定像素要求。

- 边框以薄、低对比、贴合底板为默认。采用薄金色细边或暗边，不需要处处同亮，不围成强光轮廓。矩形功能开口和安全边距保持稳定，装饰不得压缩内容。
- 在约 900 像素宽的面板上，可先以约 1–3 像素可见描边、4–8 像素窄结构带起稿；最终根据实际显示尺寸检查。内容边距另算，不能把整个安全边距做成厚金属。
- 通过轻微凹槽阴影、接触阴影和材质明暗体现层次，不把“超变”自动展开为宽金属外框、深倒角或满圈尖刺。
- 不添加多层套框、连续高亮边、大骷髅冠饰、巨型角花、龙头或独立红金标题牌。
- 标题可以直接置于低对比标题区；内部分区优先用明暗差和细暗线，不给每一块内容再套一圈装饰框。
- 只在少量边角或局部留一点红色魔纹，不沿四边铺满，不绕成第二圈边框，不穿过文字和图标。取消骷髅、血痕、火焰、尖刺、铆钉和黑铁连接件。
- 按钮使用黑底、窄金边、适度金色字面，保留浅层次和可点击感，避免演变成厚重金属铭牌。

边框过重反例的具体问题：连续尖刺外沿、多层金属套框、宽竖标题框、大骷髅冠饰、显著金色边缘、高对比红金标题牌同时叠加，使边框抢过正文和奖励。后续提示词不要把这些结构当作本套识别特征。

## 布局与控件

原型中的分区、奖励槽位、操作数量、按钮顺序与已有角色以本次要求为准。风格转换不能擅自改动规则、文案、奖励或条件。

窗口、页签、道具槽、关闭按钮与操作按钮保持同套黑金语言和稳定尺寸。选中或可操作状态通过金色明度、细边或底色深浅区分；禁用状态降低对比。奖励图标允许自身颜色，光效控制在槽内。

## 出图检查

- 第一眼能够找到标题、核心内容和主操作；边框不比核心内容更醒目。
- 按实际使用尺寸查看边框是否过宽，角饰是否挤占关闭按钮、正文或槽位。
- 整体首先读作黑金，红色魔纹仅为少量点缀；金色标题、冷灰正文清楚。
- 无黑铁、粗铸铁、铆钉结构，无骷髅、血痕、火焰与尖刺装饰。
- 图像文字逐项核对原型，特别是标题、数字、活动时段与底部小字；模糊字不猜写。
- 生成图只有经用户认可的具体维度才能升级为正例；本次边框反馈不表示用户认可其余全部设计。
