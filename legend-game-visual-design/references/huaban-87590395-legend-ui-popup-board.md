## UI 规则

- 这是功能型 UI 面板参考，不是广告图参考。目标是能承载中文、道具格、数值、按钮和状态。
- 材质优先使用黑铁、暗石、古铜、暗金、磨损银边、深棕皮革、低饱和红布。
- 内容区必须平静、低亮、可读：大面积深色矩形床、细内边框、低噪声纹理。
- 边框要像可九宫格切分：四角可有龙纹、爪形、铆钉、金属结、宝石或布带，直边连续、可拉伸。
- 弹窗结构要像真实传奇端游：顶部标题牌、右上关闭按钮、中间内容区、左侧导航或标签、右侧详情/列表、底部主按钮。
- 道具格和装备格要统一尺寸、统一间距、统一暗底，图标光效限制在格子内部。
- 按钮需要状态族：正常、悬停、按下、选中、禁用、资源不足。按钮文字短而清楚，如 强化、刷新、激活、领取、确认、前往、购买。
- 功能状态色要克制：绿色表示满足/可领取，红色表示不足/锁定，金色表示主按钮/奖励/标题，蓝青色用于选中或特殊能量。

## 分类方向

- 弹窗底框：宽面板，顶部标题条，右上关闭按钮，深色内容床，底部按钮。
- 活动/福利面板：左侧标签列表，中间奖励格，右侧说明/状态，底部领取按钮。
- 强化/合成面板：中心装备或合成槽，四周材料格，右侧属性对比，底部主操作按钮。
- 角色/装备面板：左侧角色或装备位，右侧背包格/属性列，统一暗金边框。
- 背包/道具格：方形格阵列，深色格底，细金属边，选中/锁定/不足状态清楚。
- 登录/选角面板：宽屏背景和角色槽可以更有氛围，但仍要保留可点击入口和信息层级。
- 按钮/小组件：短条形或方形，黑铁/古铜/暗金材质，状态成套输出。

## Prompt 加法

```text
参考传奇端游弹窗UI和游戏边框图风格，设计一个[弹窗/活动面板/强化面板/背包面板/按钮组/九宫格边框]。
画面结构像真实可用的传奇PC客户端界面：顶部标题牌、右上角关闭按钮、深色内容区、统一道具格/装备格、底部主按钮，必要时加入左侧标签导航和右侧详情栏。
材质使用黑铁、暗石、古铜、暗金、磨损银边、深棕皮革和少量暗红布带；边框可有龙纹、爪角、铆钉、宝石或符文点缀，但直边连续、可拉伸、内容区不能被装饰挤压。
中心内容床要低亮、干净、可承载中文说明、数值、奖励表和物品图标；按钮状态清晰，文字短促高对比，例如 强化、刷新、激活、领取、确认、购买。
整体要有传奇端游粗粝、复古、黑铁古铜质感，但布局对齐、可读性强、像可切图UI资产。
不要做成宣传海报，不要用超大广告标题，不要铺满火焰和粒子，不要让装饰压住道具格、关闭按钮、标签和中文说明。
```

## 禁用规则

- 不要使用 19157479 宣传图/买量图/banner 规则。
- 不要出现超大广告标题、战力数字、绿色买量 CTA、角色海报式构图。
- 不要把弹窗中心做成复杂场景图；中心应服务功能内容。
- 不要用现代移动端玻璃拟态、圆角卡片、柔和渐变、胶囊按钮。
- 不要让龙头、翅膀、火焰、符文侵入内容区，导致中文和道具格不可用。
- 不要输出单个孤立按钮时忽略状态族；按钮应按状态成套。
