# 用户认可的传奇圆盘面板与剧情任务图

## 来源与适用范围

用户于 2026-11-10 将本组 18 张图片明确标注为“好的传奇游戏 UI面板和剧情任务图”。按本文件编号，对应原始上传顺序；原图位于 `../assets/user-approved-ui-story-20261110/01.webp` 至 `18.webp`。

本组用于圆盘养成、神器镶嵌、八卦系统、NPC功能、专属装备任务、功法属性与剧情解锁界面。它补充现有功能 UI 规则，不把所有面板改成剧情插画，也不覆盖宣传图、按钮套件或独立 Logo 的规则。

## 圆盘与机械养成面板

参考图 01–05：

- 01：矩形薄框、顶部窄标题，六个方形槽位环绕中央机械核心。层级为核心、槽位、圆环浅浮雕、外框。
- 02：八个圆形槽位围绕八卦核心，冷灰金属细框，装饰集中在外角。
- 03：更多圆形槽位沿圆周均匀分布，中央八卦核心以少量青绿光点亮，左侧窄竖签标识功能。
- 04：独立圆盘组件，无需矩形底窗；同心圆、八个外围槽和太极中心构成完整轮廓。
- 05：盘龙包围的独立圆盘，允许更强的龙形外轮廓，龙身沿外围包裹，不占用内部槽位和核心操作区域。

可复用规则：

- 先按功能确定槽位数量、形状与顺序，再布置同心结构。六槽、八槽、多槽都是参考，不能无视任务固定为某一种数量。
- 圆槽保持直径一致，方槽保持尺寸一致；环绕中心等角排布，透视与间距稳定。中心核心与槽位不能互相遮挡。
- 材质为干燥黑铁、冷灰旧银、低饱和古铜和暗石，使用窄倒角、浅浮雕、磨损边缘与分层环轨表现厚度。
- 暗纹与符文服从圆环结构，降低对比度；空槽内部保持暗、平、干净，不默认塞入图标或虚构状态。
- 亮点集中在核心、已激活槽或当前交互点。太极、八卦和龙纹按具体主题选用，不把全部图案叠在一起。
- 组件可以是独立圆盘，也可以嵌入矩形窗。独立资产保持轮廓完整；需要透明背景时明确输出透明，不从截图里的黑色或灰格推断原图有 alpha。

## 插画式剧情与专属功能面板

参考图 06–18 表明：用户认可有主题插画的传奇游戏内功能图，而不只认可标准黑铁弹窗。

### 构图模式

- 06：左侧竖向光束与落点法阵作为功能预览，右侧安静区域承载道具和操作。光效有明确来源和范围。
- 07–08：左侧竖向题名，中部任务说明与槽位，人物或主题特效置于右侧或背景边缘。
- 09：左侧强角色轮廓，右侧短标题和功能入口，底部窄承托结构。角色可伸出内容底板形成异形外轮廓。
- 10：左侧龙与灵珠，右侧属性横行、槽位与操作区域；浅灰场景可以存在，文字区仍需清楚分离。
- 11–12：大标题配单一主题角色或神兽，说明、横排奖励槽和条件信息构成可执行任务结构。
- 13–14：人物占一侧，另一侧为说明、属性行、材料或对比区域；背景红光作为主题辅助。
- 15：冷蓝场景与大型骷髅轮廓，任务槽及属性行排列在安静内容区，青绿标题呼应主题。
- 16：左侧青色亡灵角色与外延烟雾，右侧短说明及简洁任务区域，保留暗底阅读空间。
- 17：右侧熔岩主题道具，左侧功法说明和属性横行，暖色集中在主体与关键状态。
- 18：上部龙与光环构成剧情场景，下部用分隔线组织说明、条件和任务槽，适合上下分区。

### 视觉与功能规则

- 先确认真实功能：任务说明、解锁条件、属性变化、材料消耗、奖励或入口。根据这些内容选择左右分区、上下分区或竖标题结构，不机械添加导航、关闭键、奖励栏或按钮。
- 一幅图使用一个主要叙事主体：角色、神兽、怪物、主题道具或仪式场景。主体有清楚剪影，脸部和关键特征完整，武器、翅膀、烟雾与光效不遮住任务文字。
- 插画允许占较大面积、突破底板边缘，并使用不规则外轮廓；文字和槽位仍有稳定矩形对齐区域。不要为统一外框裁掉外延主体。
- 标题可横排或竖排，字形有传奇书法、刻石或金属力量感；色彩跟随主题，字面结构清楚。生成哪些文字以用户明确提供的文案为准，不照抄样例标题，不编造奖励数值、玩法承诺或乱码微字。
- 内容底以低亮石壁、暗铁、黑褐或局部压暗场景托住说明；属性行、条件行和材料区沿固定基线排列，道具槽统一尺寸、边距和透视。
- 允许冷蓝、青绿、灰白、暗红、橙红与暗金等不同主题。主题色集中在角色、标题、法阵或局部光源，不把所有剧情图强制做成红金或均匀黑金。
- 绿色、红色、黄色等文字强调色服务于条件、属性、警示或奖励语义；若原图已有状态含义，保留映射，不凭颜色猜测规则。
- 局部火焰、雷电、烟雾、光环可用于叙事，但避开密集文字，不能均匀撒满整张图。故事感来自主体、场景与功能的对应，而非装饰数量。
- 这些图仍是游戏内剧情/功能界面。不要默认添加“立即下载”、开服日期、充值口号、二维码或宣传 CTA。

## 使用参考与验收

- 圆盘任务优先查看 01–05；场景交互优先查看 06、10、18；剧情/专属功能按构图需要选择 07–09、11–17。只查看与当前目标有关的原图。
- 学习结构、材质、主题色和信息关系，不复制具体角色、标题、徽记或剧情内容。用户明确要求保留原图内容时，按该次编辑要求执行。
- 样图分辨率很低，部分文字无法准确识别；只能据此判断视觉组织，不能声称读出了全部文案或玩法。
- 输出应保留经典传奇端游的贴图与插画气质，同时清理压缩色块、锯齿、糊字和杂乱光斑；不要把低清缩略图缺陷学成风格，也不要磨平成光滑塑料手游材质。
- 验收圆盘时核对槽位数、等距排列、核心可见与外轮廓完整；验收剧情图时核对功能是否清楚、文案是否准确、主体是否遮挡、槽位与属性行是否对齐，以及主题光是否局部可控。
