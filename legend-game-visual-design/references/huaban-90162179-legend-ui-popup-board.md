## UI 规则

- 成套 UI 必须先统一尺寸和栅格：横向弹窗建议保持接近 `1376x818` 或同类 1.65-1.7 比例。
- 每个界面都应有稳定框架骨架：顶部标题牌、右上关闭按钮、深色内容床、底部主按钮区、左右/上下分栏。
- 材质应统一在黑铁、暗石、古铜、暗金、磨损银边、暗红布带范围内。
- 同套弹窗的边框角花、内边线、按钮宽度、标签高度、道具格尺寸必须统一；变化只发生在内容、图标、标题和功能状态。
- 中心内容区要低亮、平整、可读，能放列表、奖励、属性、材料、说明文字和物品图标。
- 主按钮、次按钮、禁用按钮、已领取/已激活状态要成套，不要每个页面按钮造型都不一样。
- 道具格、装备格、奖励格要统一暗底和边框，选中/可领取/不足/锁定状态用小范围颜色区分。
- 龙纹、金属角、符文、火焰、宝石只能做身份点缀，不能吞掉标题、关闭按钮、标签、道具格和正文。

## 适用方向

- 成套活动弹窗：同一外框，不同标题和奖励列表。
- 成套强化/合成面板：同一中心槽位和材料格，右侧属性变化。
- 成套背包/装备面板：统一装备位、背包格、属性栏和按钮区。
- 成套商城/兑换面板：左侧分类标签，中间商品格，右侧价格/说明，底部购买按钮。
- 成套领取/福利弹窗：奖励格、领取状态、已领取灰态、可领取高亮。
- 成套确认/提示弹窗：小尺寸但同材质，确认/取消按钮状态一致。
