# Legend Game Visual Design

## 目标与使用方式

设计要让传奇玩家辨认出熟悉的端游气质：厚重、清楚、功能可信。保留用户指定的版式与内容，按资产类型选择材质、构图和信息层级。

用户说“用传奇技能优化此图”“按传奇技能优化”时直接使用本技能。先判断图片用途，再读取对应参考；将要求展开为具体设计语言，不把技能名、内部口令或参考板编号写进外部生图提示词。

## 共同工作要求

1. 确定资产用途、画幅、实际使用尺寸、文案和输出形式。能从用户与原图确定的内容直接采用；缺失内容影响执行时再询问。
2. 记录用户保护的边框、位置、文字、人物、Logo、二维码和内容槽。编辑时以原图为准；“保持不动”按原位置与尺寸执行，不降级为大致相似。
3. 按用途组织层级：功能窗优先任务和操作；剧情图协调叙事主体与条件信息；广告优先核心卖点；Logo优先字形。控件和信息区只按实际需求加入。
4. 保持中文、槽位、属性行和主体轮廓可读。状态颜色遵循已知含义，不凭颜色推断或编造玩法、奖励、消耗、成功率。
5. 生成或编辑后检查布局、文字准确性、遮挡、材质和实际尺寸表现。只写提示词时说明设计要求，不声称已检查生成结果。

## 做旧质感与干净度

“干净”指结构清楚、材质有控制、内容可读；允许粗粝黑铁、石纹、雕刻、氧化、缺口和磨损。保持端游贴图的颗粒尺度与边缘厚度，避免把表面磨成平滑塑料或光亮手游金属。

- 外重内静：磨损集中在外框、倒角、铆钉、标题条、按钮外壳、圆环机械和经常接触的边缘。文字底、道具槽内部和属性表保持低对比、低噪声。
- 纹理有依据：划痕跟随接触与磨损方向，氧化聚集于凹槽和连接处，浅浮雕沿结构分布。避免均匀铺满随机颗粒、裂纹和红黑污斑。
- 光效有来源：火、雷电、烟雾、法阵和主题光用于主体、状态或叙事，亮度与范围受控。正文区保留安静底面，轮廓与中文字形不被光晕吞没。
- 标准功能窗口默认干燥黑铁、暗石、冷灰旧银和少量古铜；剧情图允许青绿、冰蓝、暗红、熔岩等主题色；宣传与 Logo 按自身参考选色。
- “更干净”时先减遮挡、杂散粒子、压缩色块、糊边、过曝和内容区噪声；保留已认可的结构磨损、金属厚度与雕刻。

可用于相关改图提示词的要求：

```text
保留传奇端游粗粝黑铁、石纹、浅浮雕和边缘磨损。外框与机械结构做旧明确，文字底、属性区和道具槽内部安静清晰。清理杂散噪点、糊边与过曝光晕，保留结构厚度和干燥旧材质，避免塑料化和光滑手游金属。
```

## 输出与验收

- 学习参考的构图、材质、色彩与信息关系；具体角色、文字、徽记和图案按用户本次要求使用。
- 中文字形、数字与标识需要准确。独立无字资产不擅自添加题字；用户要求文字时使用给定文案。缩略图读不清的文字不猜写。
- 按目标使用尺寸检查文字与槽位可辨性、边框厚度、间距、对齐和主体遮挡。尺寸未知时不虚构已验证的游戏内效果。
- 圆盘额外核对槽位数量、等距排列、中心可见与外轮廓完整；剧情图核对说明、条件、材料和奖励的层级；标准 UI 核对控件及所需状态的一致性。
- 独立组件需要透明时检查真实 alpha 与完整外沿；不要把截图黑底或灰格当作透明，也不要把低清、锯齿与压缩缺陷当成参考风格。

## 工具协作

可用时用 `ui-ux-pro-max` 辅助间距与排版，并以本技能的传奇材质和功能规则约束结果。使用当前环境可用且用户指定的生图工具；若有 `api2img` 可按其说明执行。工具不可用时如实说明，不假定存在，也不自动切换到另一付费服务。参考图外传和费用遵循所用工具要求与用户已有授权。

## 学习与维护

用户提供好例、坏例、布局或风格参考时，提炼认可的具体维度与适用类别。已明确标注的资料直接处理，不重复要求标注；笼统认可的整组图可提炼共同特征，但不能替用户编造逐图偏好。保存必要原图，给详细参考建立入口，优先修正重复或冲突规则。

维护本技能时，用户要求每次更新均同步到 `https://github.com/dbaiuhd/legend-ui-training` 的 `legend-game-visual-design/`。检查远程新改动并保留无关内容，修改后运行 `skill-creator/scripts/quick_validate.py`（Windows 可用 `python -X utf8`），检查引用和素材，再提交、推送并核实远程提交。不强制推送；同步失败保留本地更新并准确说明。普通设计请求本身不表示要求修改技能或仓库。
